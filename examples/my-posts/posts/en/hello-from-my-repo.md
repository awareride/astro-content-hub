# Hello from my-posts

This post lives in the `examples/my-posts` repo. When its sync workflow runs,
it is copied into the hub's `src/content/posts/` and rendered at `/posts/hello-from-my-repo/`.

The same file under `posts/zh-Hans/` (if present, with an identical slug) provides
the Chinese version. Missing translations fall back to this English body.

Try editing this file and pushing to `main` to watch a pull request open against
the hub.
