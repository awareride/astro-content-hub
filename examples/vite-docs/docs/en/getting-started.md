# Getting Started

Create a new Vite project:

```bash
npm create vite@latest
```

Then run the dev server:

```bash
npm install
npm run dev
```

When this file is synced, the hub serves it at `/vite/docs/getting-started/`.
A `zh` version with the same slug provides the Chinese translation.
