# Vite

This page is authored in the `examples/vite-docs` repo and synced into the hub's
`src/content/docs/vite/` by the `sync-docs.yml` workflow. The product segment
(`vite`) is added at sync time from the workflow's `PRODUCT` env var, so this
repo stays flat: `docs/en/index.md`, not `docs/vite/en/index.md`.

See the [Getting Started](./getting-started.md) page for a quick tour.
