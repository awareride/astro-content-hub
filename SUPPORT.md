## Bugs and feature requests

Search the [existing issues](https://github.com/awareride/astro-content-hub/issues)
first - someone may have already reported it. If not, open a new issue and pick
the matching template (bug report or feature request).

## Questions and discussion

For "how do I..." questions that are not bugs, check the documentation above.
If it is not covered there, open a GitHub issue labeled `question` and we will
do our best to help. Please include what you tried and what you expected.
