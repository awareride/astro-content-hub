# Vite

Vite(法语意为"快",发音 `/vit/`)是一个构建工具,旨在为现代 Web 项目提供更快速、更轻量的开发体验。

开发阶段,Vite 通过原生 ES 模块提供源文件,浏览器只加载你实际导入的模块 —— 每次编辑都无需打包。生产构建时,Vite 使用 [Rollup](https://rollupjs.org/) 打包代码。

本文档是内容中心模板的示例内容。权威参考请见 [Vite 官方文档](https://vite.dev/)。
