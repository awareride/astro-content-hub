# JSON Server

JSON Server 让你用几乎零代码,从一个 JSON 文件创建假的 REST API。它常用于原型设计,
以及后端尚未就绪时的前端开发。

给定一个描述资源的 `db.json`,JSON Server 会提供 CRUD 接口,并将变更持久化回文件。

本文档是内容中心模板的示例内容。权威参考请见 [JSON Server 官方仓库](https://github.com/typicode/json-server)。
